# Documentación del proyecto Lumens

Esta carpeta concentra los requerimientos, decisiones técnicas y referencias visuales del nuevo e-commerce.

## Fuente de verdad

- `PLAN_CLIENTE_ORIGINAL.md`: alcance comercial recibido.
- `PLAN_TECNICO_ORIGINAL.md`: propuesta técnica inicial basada en Next.js/PostgreSQL.
- `brandbook/BRANDBOOK_LUMENS.pdf`: identidad visual oficial.
- `ARQUITECTURA.md`: adaptación aprobada a Laravel, MySQL y Docker.
- `EXPERIENCIA_VISUAL.md`: criterios de interfaz inspirados en Ledsion, sin copiar su identidad.

El proyecto fuente `/Users/rey/lumensistema` se considera únicamente una fuente de catálogo e inventario. No se modifica desde este proyecto.
